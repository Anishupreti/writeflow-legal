WriteFlow AI — Support

WriteFlow adds an AI writing assistant to text fields across the web. It has no server, no account system, and no login — everything below should get you unstuck without needing to wait on a reply, but reach out any time if it doesn't.

Getting started

  • No API key needed to try it. Settings → Provider is set to Mock by default — click into any text field and try the full interaction with zero setup.
  • Real generation needs your own API key from OpenAI, Anthropic, or Google Gemini, pasted into Settings. WriteFlow never sees or stores this anywhere but your own browser.
  • Pro features (every writing style, custom instructions, context-tailored replies) unlock with a one-time license key from Gumroad — no subscription.

Troubleshooting

  • The trigger doesn't appear on a site. Check Settings → Disabled Sites — that site may have been turned off from the popup's "Disable on this site" button.
  • Generation fails or shows an error. Confirm the selected Provider matches the API key you entered (an OpenAI key won't work with Anthropic selected, etc.), and that the key hasn't expired or run out of credit with that provider.
  • Pro isn't unlocking. Double-check the license key was copied in full with no extra spaces, and that you have an internet connection — verification checks against Gumroad in real time.
  • Something looks stuck or stale. Settings → Privacy & Data → "Delete all local data" fully resets the extension to a clean state.

Privacy

WriteFlow stores your settings only on your own device and sends text only to the AI provider you've configured, using your own key. Full details: Privacy Policy →
