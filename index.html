FAQ & Knowledge Base

Questions, answered honestly

Do I need to create an account?

No. WriteFlow has no account system and no login. Settings are stored only in your browser. Try the full interaction instantly with the built-in Mock provider — no API key required to see how it works.

Which AI providers are supported?

OpenAI, Anthropic (Claude), and Google Gemini. You bring your own API key for whichever you choose — WriteFlow never sees or stores it anywhere but your own device. Gemini via Google AI Studio is currently the lowest-friction option to get started: free tier, no credit card required.

Where does my text actually go?

When you request a suggestion, the relevant text — and for context-aware replies, the surrounding post or email — is sent directly from your browser to the AI provider you've configured, using your own API key. WriteFlow has no server and never sees this traffic. Full details in the Privacy Policy.

What's free vs. what's Pro?

Free: rewrite, shorten, fix grammar, and the core interaction on any field. Pro (one-time purchase, not a subscription): every writing style, custom instructions, and context-tailored comment/email suggestions.

Which websites does WriteFlow work on?

Any standard text field, plus tailored support for Gmail, Outlook, X/Twitter, LinkedIn, Reddit, YouTube, Facebook, WhatsApp Web, and Slack.

The trigger doesn't appear on a site I'm using. What do I check?
  • Settings → Disabled Sites — that site may have been turned off from the popup's "Disable on this site" button.
  • Some fields are intentionally excluded (password fields, disabled/readonly inputs) for safety.
Generation fails or shows an error — what's wrong?

Most often, the selected Provider doesn't match the API key entered (an OpenAI key won't work with Anthropic selected). Also check that the key hasn't expired or run out of credit with that provider.

Is Pro a subscription?

No. One-time payment, yours forever — consistent with WriteFlow's no-server philosophy. There's no recurring billing to manage or cancel.
